# Logos

Small icons shown next to a contact box on the profile card.

- `penn-state.png` — Penn State mark, used by the "Penn State (B.S. '28)" box.
- `rlwrld.png` — RLWRLD mark, used by the "RLWRLD (Intern)" box.

Upload them from admin.html: open Profile -> Contact -> Affiliation -> Boxes,
pick a box, then use "Upload logo...". Files land in this folder and the path is
filled in for you. Square PNG or SVG around 64x64 looks best. A missing file
simply hides the icon, so nothing breaks before you add one.
